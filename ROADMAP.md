# ROADMAP — SUDOKUFORYOU

Ogni idea si segna qui prima di farla e si spunta quando è online.

## v0.1 — Si gioca ✅
- [x] Griglia 9×9 comoda sul telefono, tema chiaro/scuro automatico
- [x] Generatore: soluzione unica, difficoltà misurata con tecniche umane (4 livelli)
- [x] Note a matita, Annulla, Cancella, evidenziazione di riga/colonna/riquadro e cifre uguali
- [x] Cifre in conflitto segnalate, note tolte in automatico dalle caselle collegate
- [x] Aiuto: segnala una cifra sbagliata oppure svela la casella più facile da trovare
- [x] Timer con pausa (anche automatica), salvataggio a ogni mossa, "Continua"
- [x] Lampo quando si completa una riga/colonna/riquadro, onda finale, statistiche per livello
- [x] Installabile (PWA), funziona offline, icona
- [x] Pubblicazione su GitHub Pages: https://jon1616.github.io/sudokuforyou/
